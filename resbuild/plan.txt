definitions: 
    the microbee palette:
        - The following colors, in order
            - 0, 0, 0
            - 192, 0, 0
            - 0, 192, 0
            - 192, 192, 0
            - 0, 0, 192
            - 192, 0, 192
            - 0, 192, 192
            - 255, 255, 255
            - 96, 96, 96
            - 255, 0, 0
            - 0, 255, 0
            - 255, 255, 0
            - 0, 0, 255
            - 255, 0, 255
            - 0, 255, 255
            - 255, 255, 255

    evlores image:
        - images use the microbee pallete
        - the image is formed of pixels that are twice as high as wide
        - each pixel can be any color from the pallete
        - images can be of any width, but must have a height divisible by 2
        - the export format is as such:
            - each byte is made up of two nibbles, the first being the bottom pixel, the second being the top pixel
            - so each row of bytes is effectively two rows of pixels

    monopixel image:
        - 
        - the image is formed of pixels that are twice as high as wide

            - it will have a byte array of characters from the text
